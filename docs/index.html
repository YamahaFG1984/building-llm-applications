AI 智能体与应用开发：从提示词到多智能体

这套教程整理自 Roberto Infante 的《AI Agents and Applications — With LangChain, LangGraph, and MCP》 及其配套代码仓库。全书的知识骨架被完整保留 —— 提示词、摘要、RAG、高级 RAG、工具智能体、多智能体、MCP、记忆与护栏 —— 但换了一种更适合初学者的讲法：先讲为什么，再画图，最后才是代码。 每一段关键代码都提供 Python、TypeScript、Java 三个版本，点一次标签，全站同步切换。

这门课要带你做出什么

大语言模型（LLM）本身只会一件事：给它一段文字，它接着往下写。 但只要在它外面搭上合适的「脚手架」，就能做出三类越来越强的应用。整套教程就是沿着这条路一步步往上爬：

📝

研究摘要引擎

问一个问题，它自己搜网页、抓正文、逐页摘要，最后写出带引用的研究报告（第 3–5 章）。

💬

旅游问答机器人

把维基、Word、PDF 喂进向量库，回答关于意大利帕埃斯图姆和英国康沃尔的问题（第 6–10 章）。

🤖

旅行助手智能体

会查资料、查天气、查酒店和民宿空房，由多个智能体协作完成（第 11–14 章）。

三种语言分别用什么

原书只有 Python。为了让不同技术背景的读者都能上手，本教程把每个示例都对照改写成了 TypeScript 和 Java。 三种语言用的并不是「同一个库的三个接口」，而是三个各自独立、理念相通的生态：

概念PythonTypeScriptJava
基础框架langchain 1.0langchain / @langchain/core 1.xLangChain4j 1.x
模型接入langchain-openai@langchain/openailangchain4j-open-ai
把步骤串起来LCEL：a | b | ca.pipe(b).pipe(c)AI Service 接口，或普通方法调用
图与智能体langgraph 1.0@langchain/langgraphLangGraph4j（社区移植）
向量库langchain-chroma@langchain/community 的 Chromalangchain4j-chroma
MCPfastmcp + langchain-mcp-adapters@modelcontextprotocol/sdk + @langchain/mcp-adaptersSpring AI MCP Server + langchain4j-mcp
结构化输出Pydantic 模型Zod schemaJava record / POJO
⚠ 关于 TypeScript 和 Java 版本，请先知道这三点
  • Python 版本来自原书仓库（个别地方做了删减和中文注释）。TypeScript 和 Java 版本是本教程对照改写的， 编写时没有逐段联机运行验证 —— 请把它们当作「同一思路在另一种语言里怎么写」的参考，而不是可以直接复制上线的代码。
  • 三个生态的版本迭代都很快，类名和包路径偶尔会调整。遇到找不到的导入时，以各自官方文档为准。
  • 有些 LangChain 的现成组件（比如 ParentDocumentRetriever、SelfQueryRetriever）在 Java 里没有一一对应的类， 这种地方 Java 版会直接手写等价逻辑 —— 这反而更容易看清它到底做了什么。

五分钟准备环境

三种语言都需要一个 OpenAI API Key（在 platform.openai.com 创建）。先把它放进环境变量：

# macOS / Linux
export OPENAI_API_KEY="sk-..."

# Windows PowerShell
$Env:OPENAI_API_KEY = "sk-..."

然后按你选的语言装依赖：

# 每章目录下都有 requirements.txt，建议一章一个虚拟环境
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r ch01/requirements.txt

# 第 1–3、6–10 章是 Jupyter Notebook
jupyter notebook ch01/01-langchain_examples.ipynb

# 第 4、5、11 章是普通脚本
python ch04/chain_try_5_1.py

// 在终端里执行：
//   mkdir llm-ts && cd llm-ts && npm init -y
//   npm install langchain @langchain/core @langchain/openai @langchain/langgraph \
//               @langchain/community @langchain/textsplitters zod
//   npm install -D typescript tsx @types/node
//
// package.json 里加上  "type": "module"
// 然后每个示例存成 .ts 文件，用 tsx 直接运行：
//   npx tsx hello.ts

import { ChatOpenAI } from "@langchain/openai";

const llm = new ChatOpenAI({ model: "gpt-5-nano" });   // 自动读取 OPENAI_API_KEY
const res = await llm.invoke("用一句话介绍你自己");
console.log(res.content);

// pom.xml 里引入 BOM，之后各模块就不用写版本号了：
//
//   <dependencyManagement><dependencies><dependency>
//     <groupId>dev.langchain4j</groupId>
//     <artifactId>langchain4j-bom</artifactId>
//     <version>1.8.0</version><type>pom</type><scope>import</scope>
//   </dependency></dependencies></dependencyManagement>
//
//   依赖：langchain4j、langchain4j-open-ai
//   后面章节会用到：langchain4j-chroma、langchain4j-mcp、org.bsc.langgraph4j:langgraph4j-core

import dev.langchain4j.model.openai.OpenAiChatModel;

public class Hello {
    public static void main(String[] args) {
        var llm = OpenAiChatModel.builder()
                .apiKey(System.getenv("OPENAI_API_KEY"))
                .modelName("gpt-5-nano")
                .build();
        System.out.println(llm.chat("用一句话介绍你自己"));
    }
}
💡 省钱小贴士

全书示例默认用最便宜的 gpt-5-nano，跑完整套教程通常只需要几美元。 只有少数需要更强推理能力的地方（SQL 生成、Supervisor 智能体）才换成更大的模型。 你也可以完全不花钱 —— 附录介绍了怎么用 Ollama 在本机跑开源模型， 三种语言都只需要改一个 baseUrl。

怎么读这套教程

  1. 按顺序读前五章提示词 → 链 → 图，这是后面一切的地基。第 4 章的研究引擎会在第 5 章被改造成图。
  2. RAG 部分（6–10）可以边读边挑第 6、7 章必读；第 8–10 章是「效果不好时的工具箱」，遇到具体问题再回来查也行。
  3. 智能体部分（11–14）是连续剧同一个旅行助手从单工具长成多智能体，再接上 MCP、记忆和护栏，建议一口气读完。
  4. 每章末尾都有动手练习不动手，看十遍也只是「眼睛会了」。
